Конструктора кидают архивы с документацией в сетевую папку, а потом эти файлы надо разложить в соответствии с принятой в 1С УНФ структурой. 
Из 1С УНФ скачивается прайс-лист, который содержит информацию о структуре номенклатуры. 
Скрипт должен прочитать файл, найти внутри местоположение изделия и перенести файл архива в соответствии с положением изделия в структуре 1С УНФ.
Скрипт готовится для использования совместно с n8n. n8n три раза в день проверяет наличие файлов в папке и при обнаружении неотсортированных материалов производит их раскладку в соответствии с принятой структурой.
Если при сортировке не удалось разместить архив, то n8n показывает ошибку и причину её возникновения.
